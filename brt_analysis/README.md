# ניתוח צמתים מרומזרים – קו כחול וקו חום (BRT)

`brt_junctions_analysis.py <ramzor.geojson> <out_dir>` מפיק:

| קובץ | תוכן |
|---|---|
| `brt_junctions.geojson` | נקודות (EPSG:2039) של הצמתים המרומזרים שבמפגש עם הקו הכחול / הקו החום שלב א' (82 צמתים) |
| `junctions_within_200m.geojson` | צמתים מרומזרים נוספים במרחק אווירי עד 200 מ' מצומת BRT (11 צמתים) |
| `brt_junctions_analysis.xlsx` | סיכום, רשימת צמתי BRT, צמתים עד 200 מ', זוגות BRT–סמוך, וצמתי החום המזרחי שהוחרגו |

הגדרות: צומת "שהקו עובר בו" = `blue_line='כן'` / `brown_line='כן'` בשכבה; קו חום = שלב א' בלבד (ראשון לציון);
מרחק = אווירי בין מרכזי הצמתים. שכבת המקור (12MB) אינה נשמרת ברפו.
